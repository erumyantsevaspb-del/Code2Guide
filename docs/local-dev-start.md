# Локальный запуск Code2Guide на Windows

## Почему нужен start_dev.bat

Django по умолчанию пишет логи в консоль cmd.exe.  
На Windows включённый **Quick Edit Mode** блокирует вывод в консоль, если
пользователь случайно кликнул по окну терминала — это приводит к зависанию
генерации до нажатия Esc.

`scripts/start_dev.bat` перенаправляет весь вывод в файл и запускает сервер
без авто-перезагрузки, поэтому работа сервиса не зависит от состояния терминала.

## Запуск

Дважды кликнуть по файлу или запустить из cmd:

```bat
scripts\start_dev.bat
```

Окно консоли можно свернуть или закрыть — генерация продолжится.

## Диагностика

Все логи Django (включая ошибки генерации и скриншотов) пишутся в:

```
logs\django-dev.log
```

Логи скриншотов конкретной генерации:

```
media\screenshots\<project_id>\gen_<generation_id>.log
```

## Остановка сервера

Нажать **Ctrl+C** в окне консоли или завершить процесс `python.exe` в диспетчере
задач.

## Планировщик задач (автозапуск)

Чтобы сервер запускался автоматически при входе в Windows, создайте задачу в
Планировщике задач (аналогично инструкции в `docs/windows-task-scheduler.md`),
указав в поле «Программа»:

```
C:\Users\Lena\Code2Guide\scripts\start_dev.bat
```
