# Автоматическая очистка зависших генераций — Windows Task Scheduler

Скрипт `scripts\repair_stuck_generations.bat` запускает `manage.py repair_stuck_generations` и записывает результат в `logs\repair_stuck_generations.log`.

## Создание задачи (один раз)

1. Открой **Планировщик заданий** (`Win+R` → `taskschd.msc` → Enter).

2. В правой панели нажми **Создать задачу** (не «Создать простую задачу»).

3. Вкладка **Общие**:
   - Имя: `Code2Guide — очистка зависших генераций`
   - Установи флажок **Выполнять вне зависимости от регистрации пользователя** — задача будет работать в фоне, без открытого браузера.
   - Флажок **Выполнять с наивысшими правами** — снять (обычных прав достаточно).

4. Вкладка **Триггеры** → **Создать**:
   - Начать задачу: `По расписанию`
   - Повторять: `Ежедневно`, начиная с сегодняшней даты
   - Установи флажок **Повторять задачу каждые**: `5 минут`, в течение `1 дня`
   - Флажок **Включено**: установить
   - Нажми **ОК**.

5. Вкладка **Действия** → **Создать**:
   - Действие: `Запуск программы`
   - Программа или сценарий: `C:\Users\Lena\Code2Guide\scripts\repair_stuck_generations.bat`
   - Рабочая папка: `C:\Users\Lena\Code2Guide`
   - Нажми **ОК**.

6. Вкладка **Условия**:
   - Снять флажок **Запускать задачу только при питании от сети** (если нужно на ноутбуке).

7. Нажми **ОК**. Введи пароль учётной записи, если запросит.

## Проверка

Правая кнопка на задаче → **Выполнить**. Затем проверь файл:

```
C:\Users\Lena\Code2Guide\logs\repair_stuck_generations.log
```

## Отключение

Правая кнопка на задаче → **Отключить** (задача остаётся, но не запускается).
