# Code2Guide

Сервис для автоматической генерации пользовательской документации из React-проектов.
Анализирует исходники (ZIP или Git-репозиторий), извлекает маршруты, делает скриншоты
и собирает PDF с пошаговыми инструкциями.

## Требования

- Python **3.12+**
- Node.js и npm (для запуска React-проектов при генерации скриншотов)
- Git (для загрузки проектов по ссылке)

## Установка

```bash
# 1. Клонировать репозиторий
git clone <repo-url>
cd Code2Guide

# 2. Создать виртуальное окружение
python -m venv venv

# Windows
venv\Scripts\activate

# Linux / macOS
source venv/bin/activate

# 3. Установить зависимости
pip install -r requirements.txt

# 4. Установить браузер Playwright (отдельный шаг, обязателен для скриншотов и PDF)
python -m playwright install chromium

# 5. Применить миграции
python manage.py migrate

# 6. Создать администратора (опционально)
python manage.py createsuperuser
```

## Запуск

### Windows (рекомендуется)

```bat
scripts\start_dev.bat
```

Скрипт запускает сервер и пишет логи в `logs\django-dev.log`.
Окно консоли можно свернуть, но не закрывать — закрытие остановит сервер.

### Linux / macOS

```bash
python manage.py runserver 127.0.0.1:8000
```

Открыть в браузере: http://127.0.0.1:8000

## Тесты

```bash
pytest tests/
```

## Что делает сервис

- **ZIP-режим** — загрузить архив React-проекта; сервис устанавливает зависимости,
  запускает dev-сервер, делает скриншоты каждой страницы и генерирует PDF
- **Git-режим** — указать URL публичного репозитория; сервис клонирует и делает то же самое
- **Внешний URL** — указать адрес уже запущенного приложения (с логином/паролем или без)

## Ограничения

- Инструкции генерируются по шаблонным правилам (не LLM/AI)
- Скриншоты — видимая область 1280×800, не полная прокрутка страницы
- Поддерживаются React-проекты (Vite, CRA, Next.js, NX monorepo)
- Динамические маршруты (`:id`, `[slug]`) не скриншотируются — нет реальных данных

## Структура логов

```
logs/django-dev.log                         — логи Django
media/screenshots/<project_id>/gen_<id>.log — логи конкретной генерации
```
