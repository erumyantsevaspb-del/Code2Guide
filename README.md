## Code2Guide — веб-приложение для автоматической генерации пользовательской документации на основе исходного кода пользовательского интерфейса.

Проект разрабатывается в рамках образовательной программы «Стартап как диплом» и является выпускной квалификационной работой.
Автор: Елена Румянцева

## Статус проекта

🚧 Проект находится в активной разработке.

На текущий момент реализованы:

 - создание проектов;
 - анализ структуры React-приложения;
 - генерация пользовательских инструкций;
 - формирование документации;
 - предпросмотр документа с титульным листом, содержанием и страницами инструкций.

## В разработке:
 - навигация по страницам документа;
 - улучшение качества автоматически генерируемых инструкций.
